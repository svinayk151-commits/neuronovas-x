# GoodPlate — five-minute demo

1. **Donor lists food:** Log in as `donor1@demo.com` / `Donor@123`. Create a surplus listing, set quantity and pickup/use-by times, add handling notes, and publish with the required safety attestation.
2. **Recipient requests:** Log in as `recipient1@demo.com` / `Recipient@123`. Search/filter for the listing, choose a quantity below the remaining amount, add a pickup note, and confirm they can collect in the window.
3. **Donor accepts:** Log back in as the donor. Accept the pending request and show the atomically reserved quantity and request history timeline.
4. **Pickup & history:** Mark the accepted request as picked up. Show the reference code confirmation, then the completed request on the donor and recipient dashboards.
5. **Admin moderation:** Log in as `admin@demo.com` / `Admin@123`. Review/action a report, remove a questionable listing with a reason, and show that the donor receives an in-app notice.

Use fictional details only. GoodPlate coordinates pickups; it does not certify food safety.
